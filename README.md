# Oasis of Kings - Digital Agency Website

A modern, responsive, SEO-optimized digital agency website built with HTML, JavaScript, and Tailwind CSS.

## Features

✨ **Modern Design**
- Trending web design patterns
- Responsive layout (mobile, tablet, desktop)
- Smooth animations and transitions
- Professional gradient color scheme
- Dark mode optimized footer

📱 **Pages Included**
1. **index.html** - Homepage with:
   - Hero banner section
   - Services showcase (6 services)
   - Portfolio/Project samples (6 projects)
   - Client testimonials (3)
   - FAQ section (5 FAQs)
   - Call-to-action sections
   - Optimized footer

2. **about.html** - About Us page with:
   - Company story
   - Mission & Vision
   - Core values (6 values)
   - Key statistics
   - Team members
   - Why choose us section

3. **contact.html** - Contact Us page with:
   - Contact form (with validation)
   - Business hours
   - Contact information
   - Social media links
   - FAQ section
   - Professional layout

🔍 **SEO Optimization**
- Meta tags for all pages
- Open Graph tags for social sharing
- Semantic HTML structure
- Canonical URLs
- Mobile-first responsive design
- Fast loading with optimized images
- Proper heading hierarchy
- Alt text for images
- Internal linking structure

🎨 **Design Features**
- Custom gradient styling
- Smooth scrolling
- Hover effects
- Alpine.js for interactivity
- Tailwind CSS for styling
- Professional typography
- Accessibility-friendly

⚡ **Performance**
- CDN-based resources (Tailwind, Alpine.js)
- Optimized images
- Clean, efficient code
- Fast page load times
